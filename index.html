THE CORE IDEA

Small. Fast. Close to the CPU.

Cache keeps copies of selected data from main memory so the processor can access that data more quickly.

LEARN THE FUNDAMENTALS

Cache Memory Theory

Understand each concept before trying the simulator.

01

Main Memory (RAM)

Main memory stores the programs and data the computer is currently using. It has much greater capacity than cache but is generally slower to access.

02

Cache Memory

Cache is small, fast memory located close to or integrated with the processor. It stores copies of selected data from lower memory levels.

03

Cache Hit

A hit occurs when the processor requests data that is already present in the cache.

04

Cache Miss

A miss occurs when the requested data is absent from the cache. The system must fetch it from a lower memory level.

IMPORTANT CONCEPTS

How Cache Works

Locality of Reference

Programs tend to reuse recently accessed data (temporal locality) and access nearby memory locations (spatial locality). Cache takes advantage of these patterns.

Cache Hit Ratio

The proportion of memory requests that are found in cache.

Hit Ratio = Cache Hits / Total Memory Accesses

Cache Miss Ratio

The proportion of memory requests that are not found in cache.

Miss Ratio = Cache Misses / Total Memory Accesses

MAPPING TECHNIQUES

Where Does a Block Go?

Mapping determines where a main-memory block can be placed in cache.

01

FIXED DESTINATION

Direct Mapping

Each main-memory block can occupy exactly one cache line.

Cache line = Block number MOD Number of cache lines

Example

For block 6 and 4 cache lines:

6 MOD 4 = 2

Block 6 must be placed in cache line 2.

Advantages
  • Simple and inexpensive
  • Fast to locate a line
Disadvantages
  • Blocks may compete for one line
  • Can cause conflict misses
Doraemon example: Every gadget has one specific pocket slot assigned by its block number.
02

ANY DESTINATION

Fully Associative Mapping

A memory block can be placed in any available cache line.

Any memory block → Any cache line

Example

With 4 cache lines, block 6 can be placed in line 0, 1, 2 or 3 if the line is available.

Advantages
  • Flexible placement
  • Fewer placement conflicts
Disadvantages
  • Requires searching tags
  • Hardware is more complex
Doraemon example: A gadget can go into any free pocket space.
03

GROUPED DESTINATIONS

Set-Associative Mapping

Cache is divided into sets. A block maps to one set, but can occupy any line within that set.

Set number = Block number MOD Number of sets

Example

With 4 cache lines and 2-way associativity, there are 2 sets with 2 lines per set. Block 6 maps to set 0 because 6 MOD 2 = 0.

Advantages
  • Balances flexibility and cost
  • Reduces some conflict misses
Disadvantages
  • More complex than direct mapping
  • Blocks can still compete within a set
Doraemon example: A gadget is assigned to one pocket section but can use either slot in it.

Compare the Mapping Techniques

Feature Direct Fully Associative Set Associative
Block placement One specific line Any line Any line in its set
Placement flexibility Low High Medium
Hardware complexity Low High Medium
Main conflict risk Blocks sharing a line Lower placement restriction Blocks sharing a set

HOW TO SOLVE

Direct Mapping: Find the line

Calculate the remainder after dividing the block number by the number of cache lines. That remainder is the only valid destination.

Line = Block number MOD Number of cache lines
  1. Read the memory block number.
  2. Divide it by the number of cache lines.
  3. Use the remainder as the line number.
